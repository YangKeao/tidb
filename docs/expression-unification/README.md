## This checkpoint
- **Construction and shared leaves:** TiKV owns the native date constructors, MAKETIME parts arithmetic and the sole migrated duration formatter. Native inverse-civil conversion thin-delegates the original i64 algorithm, including ordinary overflow behavior; different TiKV wire domains are not substituted. The formatter preserves NaN/infinity/negative-zero behavior, shortest-decimal half-up rounding and second-only fraction carry without minute/hour normalization.
- **Actual typed inputs:** four operations return three ordinary OwnBytes results and one existing OwnIeee754Bits result. MakeTimeParts is the sole new role: nullable B9 (LE i64 hour plus actual UInt flag 0/1), Int minute and B8 second bits, with isolated exact-operation metadata. SEC_TO_TIME reuses Ieee754BitsInt with separate coupling: None/None means actual NULL seconds and undemanded FSP; Some/Some requires nonnegative, usize-representable FSP. No 0..6/u8 truncation: raw Time FSP 7 and original Duration conversion panics remain. Old ROUND/TRUNCATE branches are unchanged; no new result kind, report, cause, driver, NoArgs or native PB/legacy admission.
- **Demand and resource order:** MAKEDATE retains both ordered conversions; MAKETIME retains all three, including third-argument warnings after an earlier NULL. MAKETIME uses two complete sequential calls, not recursive callbacks: first worker produces actual total-second bits or NULL; only success demands original FSP before the shared formatter call. There is no host range prediction or computed answer. First admission can precede FSP preparation; two leases, result transport and two one-shot executions without context capability are explicit costs. SEC_TO_TIME uses one call and demands FSP only for non-NULL numeric input.
- **FROM_DAYS packing:** only the provider's actual canonical `0000-00-00` bytes restore the original typed zero Time(Date, FSP 0). Host packing neither inspects the original day number nor parses/classifies it; the bytes are a real date value, not a marker. Other dates remain strings and the original exceptional NULL band remains worker-owned, preserving subsequent typed casts.
- **Scope:** 14 Rust files (TiKV 8/native 6); no manifest changes or metadata commands. Both lockfiles are byte-identical to this round's HEAD. The previous auth-leaf dependency/lock changes are historical, not current changes.
