## Shared ownership

TiKV datatype `native_value.rs` owns the original construction/setter/validation policy and complete nine-variant NativeTimeError. Native TimeType aliases the existing TiKV enum (only Eq/Hash added), and TimeError aliases the shared error. Native Time retains its separate raw/kind/FSP storage and thin projections, not wire Time storage semantics. DATE construction does not clear hidden clock or raw bits; DATE ignores constructor FSP, while set_fsp preserves even synthetic raw255. Checked fields precede FSP. TIMESTAMP raw0 bypasses timezone validation, whereas reserved-only raw bits do not; conversion errors precede the original seconds range check.

`native_time_parser.rs` owns DATE/DATETIME/TIMESTAMP string and numeric parsing, consuming actual text/i64/f64, the original Decimal Display representation, three conversion-policy booleans and the actual generic timezone. Native ParsedTime/error-side outcomes are pure projections via from_raw_parts, never a second construction/validation. Shared outcomes retain typed fallback values and both truncation/DST-adjustment flags.

Ordering remains: float-string0.0 prefix before FSP, other string FSP before parsing even for DATE, fractional carry in the session instant before suffix conversion, then typed construction/validation and optional gap adjustment/revalidation. Numeric0 bypasses FSP but retains independent zero-date policy; classified int0 is DATE0. Float preserves Rust casts including NaN→0, original fractional rounding without carry/revalidation and FSP0. Decimal preserves original Display text, truncation rather than rounding, DATE FSP no-op and DATETIME-zero error-side values. No native parsed answer or callback enters the SDK. YEAR/INTERVAL, other temporal methods and evaluator closure are outside this slice.

`native_session_time_zone.rs` owns the unchanged native zone implementation; native types are aliases with original Debug names. Local/Named clock observations, Fixed raw name/offset metadata, conversion-only offset clamp, strict UTC name checks, ambiguity ordering and from_offset's Fixed reconstruction remain. Wire Tz is not a replacement.
