# 混合 IF 的批量分支

task #68 产品和测试固定为 TiDB `19b952f1a83602218e43f131febeb0e4b639b3e6`。SDK 仍为 `47c439a980528603ef437ec8a682b67d5b5bfba3`。

直接有符号 BIGINT 条件与原生 MD5 字节列、JSON_TYPE 列进入已有的批量 IF 分支。根据条件分组读取选中的物理行，再按原顺序合并结果。其他表达式继续沿用原调度判定。带 BENCHMARK 的条件保留按行执行。

类型化测试以 [7,2,7] 验证未选的畸形 JSON。活跃错误仍返回原 3140，并保留已写输出。实际 SQL 的观测输出确认进入批分支，字段、结果和告警仍一致。73 项共享表达式、19 项 SQL、独立 SDK 444 项及限定 Clippy、根 lint 和格式通过。
