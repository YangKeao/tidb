# HEX 和 UNHEX 的类型化执行

task #75 固定为 TiDB `bfb3e8f43dfae500fb56be2f124c55e68bb6e54c` 和 SDK `070c1b2cad01fe60ecc4fdb108fbd824bb7c4ca0`。

HEX 对已定型的 BIGINT 和原始字符串调用 SDK 的整数或字符串实现，保留完整的 64 位值。UNHEX 对已定型的字符串调用 SDK 解码，保持奇数位左补零、无效字节返回 NULL 和二进制字段声明。需要数值或字符串转换的其他签名继续使用原路径。

实际 SQL 投影计数从 (0,0) 变为 (1,1)。字段、告警和结果一致，覆盖负一、有符号最小值、无符号最大值、非 UTF-8 字节、空串和 NULL。另验证 DECIMAL HEX 和数值 UNHEX 的回退。78 项共享表达式、25 项 SQL、限定 Clippy、格式及根 lint 通过。本批未测性能。
