# CRC32 与 UNCOMPRESSED_LENGTH 的字节内核

TiDB 固定在 3e038ddd63718a8080d2f86769770ac47a6a66de，SDK 固定在 cf7dc12be2036240972972d925a5b9e49a968c98。

类型化二进制输入复用 SDK 原有 CRC32 与长度前缀内核。实际 SQL 核对了非 UTF-8 字节、空串、NULL、完整 u32 前缀和两项短载荷 1259。另用同一 IF 对齐 1259、1365 告警顺序。SDK 通过现有 FnCall 转交标记内核的告警，保留独立 PB 上下文的告警收集。

最初测试复现 SDK 告警未抵达语句。接线修正后复现 SDK 序列化前缀差异，再核对完整文案。81 项共享表达式、48 项 SQL、569 项独立 SDK 测试、限定 Clippy 和根 lint 通过。性能未测。

同期按原 245 族清单复核，76 族有至少一种限定原生接纳，164 族未建立对应接纳，另有 5 个历史例外。双仓相对原始基线总增删 22,003 行，其中生产 7,983 行、测试 11,144 行、构建 2,096 行、文档 780 行。默认入口、旧实现退役、全量测试及性能仍待验收。
