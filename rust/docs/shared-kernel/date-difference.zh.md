# 类型化 DATEDIFF

TiDB 源码固定在 `e321f64279234e4628d67129832c7a79d54656c1`，SDK 固定在 `0521b09369455887732a1fa54f6292f0515f1318`。

DATEDIFF 从两个已类型化的日期表达式取值，调用现有 SDK 日期差。原生参数按 DATETIME 进入日期转换，使原日期差计算先清除所有钟面，再校验日历字段。PB 保留自己的入参形状，已有 DATE 载体的隐藏钟面仍按原合同参与。

SQL 对照覆盖零年闰日、跨年日期、方向、非法日期、NULL，并验证 DATEDIFF 接受 DATE(t) 的计算结果。直接 Chunk 对照带隐藏钟面的 DATE，区分同一组值的原生一天与 PB 零天，并检查两种输出、重排和重复行。两项改动前的失败均保留。

88 项共享表达式、81 项执行器集成、独立 SDK 的 448 项表达式、122 项执行器和 3 项 Endpoint 测试通过，限定 Clippy 和根 lint 通过。性能未测。
