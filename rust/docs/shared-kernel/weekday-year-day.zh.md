# 类型化日期的星期和年内日序

TiDB 源码固定在 `6c0ce795bd635b2e366f02f9f61fe1bb72e6b479`，SDK 固定在 `4d1a217165c1c2e7c913a9d9deec772dd7d2a996`。

DAYOFWEEK、WEEKDAY 和 DAYOFYEAR 通过原共享程序读取原生日期载体。星期分别以周日为一和周一为零。年内日序从一开始，并计算公历闰日。原生入口对零月、零日、无效月日返回 NULL，PB 的原有零日期告警或错误仍在签名入口处理。

SQL 对照覆盖 DATE 与 DATETIME 列、两套日期模式、零及无效日期、NULL、闰日与零年三月一日。改动前原始结果一致，共享程序计数为零。85 项共享表达式、75 项执行器集成、独立 SDK 的 448 项表达式、122 项执行器和 3 项 Endpoint 测试通过，限定 Clippy 和根 lint 通过。性能未测。
