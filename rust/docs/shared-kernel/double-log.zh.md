# DOUBLE 对数的定义域和告警

TiDB 源码固定在 `6bcc9d1a28878b22321d900e8d56b095826b2f0f`，SDK 固定在 `0651c5eb5005184d6fa776ae5fbac98c27e3a621`。

已类型化 DOUBLE 的 LN、单参数 LOG、双参数 LOG 和 LOG2 进入原共享表达式程序。入口接受直接列和字面量，保留语句的逐行告警时机。两参数 LOG 先核对两个输入的 NULL，再检查底数和真数。原生域外值返回 NULL 并追加 3020，PB 仍只返回有限值或 NULL。LOG10 继续使用自己的 Go 兼容算法。

SQL 对照检查七行结果、一个共享程序及九条原生 3020 告警。相同 SQL 在改动前得到相同结果，未进入共享程序。直接 Chunk 对照包括 NaN、正负无穷、负零、NULL、重复行号与重排，分别覆盖持有值和直接写出。PB 回归向量增加非有限输出用例。

85 项共享表达式、73 项执行器集成、独立 SDK 的 448 项表达式、122 项执行器和 3 项 Endpoint 测试通过。限定 Clippy 和根 lint 通过。性能未测。
