# 二进制 LPAD 和 RPAD

TiDB 固定在 `eecd01e695dbc2b1f264cb8ff76ea0e2792e1f75`，SDK 固定在 `4473eac0e7347d4c145e7d6c582bb02ee5758b33`。

共享投影接纳二进制字节串和有符号 BIGINT 长度。正向填充复用 SDK 内核。截短或等长按字节保留输入前缀，空填充串遇到需要增长的输入仍返回空串。二者均复用当前语句的 1301 策略。

实际 SQL 在 4 字节限制下核对了负长度、双 NULL 参数的原生宽度估计、刚好达到上限、原字节和值为空的情况。84 项共享表达式、69 项执行器集成、独立 SDK 的 447 项表达式、122 项执行器和 3 项 Endpoint 测试通过。限定 Clippy 和根 lint 通过。性能未测。
