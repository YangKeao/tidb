# 混合 IF 的 release 求值成本

task #67 使用 TiDB `ea2a4b435ae62c10412cbca0eb15e03afdb7395f` 和 SDK `47c439a980528603ef437ec8a682b67d5b5bfba3`。同一个 release 二进制对照原生 EvaluatorSuite 和共享投影，计算 `IF(flag, MD5(s), JSON_TYPE(j))`。两条路径复用同样的输入和输出配置，计时前后逐行验证结果，准备和输入生成在计时之外。

在 Ryzen 9 9900X 的 CPU 23 上执行六轮配对试验，每轮交替两条路径的先后顺序。使用 opt-level 3、关闭 LTO、16 个 codegen units。32 和 1024 行时两分支各处理一半数据。1 行时选择 JSON 分支。JSON 文本内容长度为 3 或 4096 字节，表中时间单位为纳秒每批。

| 行数 | JSON 字节 | 原生中位数 | 共享中位数 | 配对比值中位数 | 观测范围 |
| ---: | ---: | ---: | ---: | ---: | ---: |
| 1 | 3 | 200.976 | 741.625 | 3.719 | 3.448–3.787 |
| 1 | 4096 | 233.215 | 835.556 | 3.609 | 3.457–3.745 |
| 32 | 3 | 7741.620 | 18900.483 | 2.441 | 2.328–2.529 |
| 32 | 4096 | 8635.454 | 20662.649 | 2.402 | 2.313–2.476 |
| 1024 | 3 | 247613.802 | 570383.692 | 2.294 | 2.183–2.405 |
| 1024 | 4096 | 290674.466 | 652280.836 | 2.244 | 2.139–2.303 |

此场景的共享执行耗时为原生的 2.24–3.72 倍，以配对比值中位数计。试验未隔离 CPU，也未测分配或服务端 SQL。结果用于定位这一组分支的求值成本，完整性能验收仍有待验证。

`evidence/mixed-if-cost/` 保存 72 个计时单元、二进制和 12 个直接构建产物。试验开始前校验链接来源与哈希。全量清单包含 41 条记录，`SHA256SUMS` 的 SHA-256 为 `8751888bc0108b9c50b6fa502851e946a63564c241a2154a4da92fc356a263de`。本批产品和测试增删均为 0，说明材料增删 19 行。双仓原始基线累计源码和测试增删 15,486 行，含材料增删 17,947 行。
