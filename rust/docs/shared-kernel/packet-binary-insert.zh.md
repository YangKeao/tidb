# 字符串 INSERT 的二进制替换

TiDB 固定在 `9d76d4d07b1635ebafc92ba3e290162af859719c`，SDK 固定在 `d57d6591fcb62c5afd0782f18e5616ab812d9ed4`。

共享投影接纳二进制原串和替换串、类型化 BIGINT 位置和长度。原生 SQL 和 PB 共用字节区间计算和写入。负长度替换到末尾，越界位置返回原串，NULL 仍传播。原生 SQL 在分配前按最终结果大小检查当前语句的包限制，越界返回原串时也检查；PB 的原签名继续直接产生字节结果。

实际 SQL 的 4 字节限制用例核对了原字节、刚好达到上限、增长超限、越界时原串超限和大范围替换后仍低于限制。84 项共享表达式、70 项执行器集成、独立 SDK 的 447 项表达式、122 项执行器和 3 项 Endpoint 测试通过。限定 Clippy 和根 lint 通过。性能未测。
