# INSERT SELECT 的共享算术源投影

TiDB 固定在 6dc27958032151dbf778b2fa843f919a4950b55c，SDK 固定在 2e123f71eb9b20e6e46b32110d60f895f7d8830b。

显式开启实验时，INSERT SELECT 的串行源投影接纳 UPDATE 已验证的有符号 BIGINT 两叶加减乘，并保留原列直通。真实 SQL 用两批各一行确认成功写入、第二批源溢出 1690 及第二行目标 TINYINT 转换 1264。两类错误均保留目标表原状态。超出该形状的 ABS 源投影继续走原入口。

81 项共享表达式、57 项执行器集成测试和 INSERT 筛选的 21 项通过，筛选另有 2 项忽略。功能关闭构建、限定 Clippy 和根 lint 通过。性能未测。
