# DOUBLE 幂运算和角度转换

TiDB 源码固定在 `252c1fe5c5c96d243cfaa11323ee249630442403`，SDK 固定在 `e8592fa6feab380d4bebef310b7c38a64a3917d2`。

直接 DOUBLE 列和字面量的 POW、POWER、RADIANS、DEGREES 使用共享值计算。原生入口在非有限结果上返回 1690，幂运算用原生表达式渲染，角度转换保留通用 DOUBLE 溢出文案。PB 各签名继续执行原有的输出检查。

真实 SQL 对照覆盖四个调用、两侧 NULL、负底数产生的 NaN、正向溢出及完整错误文案。改动前结果相同，共享程序计数为零。85 项共享表达式、74 项执行器集成、独立 SDK 的 448 项表达式、122 项执行器和 3 项 Endpoint 测试通过，限定 Clippy 和根 lint 通过。性能未测。
