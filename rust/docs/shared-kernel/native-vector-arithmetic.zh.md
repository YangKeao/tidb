# 类型化向量加、减和乘

TiDB 固定在 18d585f86425bb91c2d1494d80db4463bcea2a2c，SDK 固定在 6d1962b7d21c4ddcf952da9d5ceb76163e42535b。

类型化向量加、减、乘的 RPN 调用复用已有 datatype 运算，支持将结果继续用于 VEC_DIMS。真实 SQL 核对正负零的 float32 字节、空向量、输出声明和 NULL。左值 NULL 时，右侧 CAST 的非法输入仍报错。维度不符和元素超范围的 1105 与原求值器逐字一致。

81 项共享表达式、47 项 SQL、569 项独立 SDK 测试、限定 Clippy 和根 lint 通过。运算通过现有向量编码桥读取左右值并复制输出，沿用原求值顺序，性能未测。
