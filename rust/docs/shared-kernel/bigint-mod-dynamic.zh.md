# BIGINT MOD 的动态除数

81 项共享表达式、34 项 SQL 和 569 项独立 SDK 检查通过。验证保留了初次测试误用词法 SQL 模式接口及测试辅助函数未覆盖除零错误的失败记录。未测性能。
