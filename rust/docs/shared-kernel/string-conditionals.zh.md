原生 IF、CASE、IFNULL 和 COALESCE 继续使用同一按需控制。可选结果为已绑定的字符串列、同一排序规则的 String 值或类型化 NULL。Row 和 owned 投影保留被选中字符串的字节及实际排序规则，Chunk 保留原输出字段声明。SDK 仅扩展非 NULL 跳转接纳的栈类型，复用已有的字节和 NULL 判断。SETVAR 接纳范围沿用原约束。
