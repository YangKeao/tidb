# BIGINT 的 NOT、NULL 与真假判断

task #60 的产品和测试固定在 `0f5f31611ce4dfb5bafab823e96e25a0be40b9be`。独立 SDK 固定在 `1290817a57f7c8e88d52f64a1754b0e67712cec1`，本批无 SDK 变更。

有符号及无符号 BIGINT 的 NOT、IS NULL 与真假判断复用 TiKV PB 已用的整数元信息。反向判断复用原有 NOT。超过有符号范围的整数按原始 64 位读取，NULL 处理取决于具体判断。直接列或字面量的谓词可以按批求值，复合表达式继续保留原有按行选择。接纳要求结果为有符号 BIGINT。

测试对两种符号组合及九种内部判断名称核对 NULL、零、最高位和全一位，并包含乱序重复行。实际 SQL 投影与 Selection 都从 (0,0) 变为 (1,1)，输出字段、结果和告警一致，保留 ID 1、3、4。另一个 Selection 中 NULL 行跳过 BENCHMARK，其余三行分别抽取两次 RAND，原与共享均恰好六次。

固定版通过 69 项共享表达式、13 项 SQL 及独立 SDK 444 项。限定 Clippy、根 lint 和格式通过。本批未测性能。验证目录 `evidence/bigint-truth/` 保留 11 对跟踪源码树，6 对对应固定检查。跟踪树与补丁未覆盖完整构建依赖。清单包含 51 条记录，`SHA256SUMS` 的 SHA-256 为 `9d446661576371ad1032fdf365efedc3d2ef3210da2bdb0ea398ac7a560a52c2`。
