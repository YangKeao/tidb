# SPACE 和 REPEAT 的包大小限制

TiDB 固定在 `8f04883c4486227e968ea92549789bc7ec0aa9b2`，SDK 固定在 `f4be52717608b23ebc9f5f070e6314e694ba7093`。

本地共享投影接纳 BIGINT 宽度或次数、以及 REPEAT 的类型化字符串。共享程序在分配结果前读取当前语句的 `max_allowed_packet`，调用语句原有的 1301 诊断，再复用 SDK 字节结果内核。SPACE 先检查包大小，再检查 BLOB 宽度。PB 的原签名仍直接使用相同字节内核。

真实 SELECT 用 4 字节限制核对刚好达到上限、逐字节结果、NULL、负数、极大次数时的空串及告警顺序。独立语句上下文的对照保持告警级别和文本一致。直接求值验证严格语句返回 1301，另一个较大包限制下超过 BLOB 宽度只返回 NULL。

83 项共享表达式、66 项执行器集成、独立 SDK 的 446 项表达式、122 项执行器和 3 项 Endpoint 测试通过。限定 Clippy 和根 lint 通过。性能未测。
