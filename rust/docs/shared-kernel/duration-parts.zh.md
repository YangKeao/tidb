# 类型化 TIME 列的分量和整秒

TiDB 源码固定在 `053047b5cd7a6ba72359650ed1c3c47a70c5fbbd`，SDK 固定在 `e193981703394becacc4ff9d067534615fd0d315`。

HOUR、MINUTE、SECOND、MICROSECOND 和 TIME_TO_SEC 共享 TIME 分量计算。原生列保留有符号纳秒和声明 FSP。小时、分钟和秒返回幅度，整秒保留符号，微秒按原生列精度截断。在原始超界值上，原生前三个分量按原规则截到 838:59:59，微秒和整秒执行各自原范围规则。PB 保留原有值域和输出。

实际 SQL 覆盖 TIME(3)、TIME(6)、负数、极值、零和 NULL。直接 Chunk 用例对照了比声明精度更长的原始小数、超界值、最小纳秒、重排及重复行，检查持有值和直接写出。两项改动前的反例均保留。

87 项共享表达式、79 项执行器集成、独立 SDK 的 448 项表达式、122 项执行器和 3 项 Endpoint 测试通过，限定 Clippy 和根 lint 通过。性能未测。
