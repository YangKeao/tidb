回归测试用真实表和 PreparedSelectPlan 保留的物理计划执行同一条查询。第一次绑定 1.50 并创建缓存，第二次命中缓存并绑定 -2.00。两次执行都断言计算投影走共享路径，完整结果字段、数据、NULL 和告警与同一物理计划走原求值器一致，另以直接 SQL 字面量校验结果值。
