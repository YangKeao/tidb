# Base64 的包大小与编码约定

TiDB 固定在 `f7ab3ad24dd2066a6906b82f0c6c571401e2a911`，SDK 固定在 `d4a0b25d60688708a845f1cf1bc51a858f7d99f5`。

类型化 TO_BASE64 和 FROM_BASE64 共用 SDK 编解码，在分配前应用当前语句的包大小限制。编码保留 76 列换行。解码根据原输入长度检查上限，随后按原生规则去除空格、制表符和换行，拒绝非规范填充，并保留二进制结果。原 PB 签名遇到不完整填充时的空串，以及对纵向制表和换页字符的忽略均有单独对照。

实际 SQL 核对 4 和 1024 字节限制、NULL、原字节、换行与 1301 告警顺序。84 项共享表达式、68 项执行器集成、独立 SDK 的 447 项表达式、122 项执行器和 3 项 Endpoint 测试通过。限定 Clippy 和根 lint 通过。性能未测。
