# ELT 和 MAKE_SET 的类型化字符串选择

TiDB 固定在 `89ee0132e5f92fc95b935c43058003c45caa323b`，SDK 固定在 `86237086303399aed3bd0e0493431f2465789050`。

二进制 ELT 复用 SDK 的位置选择，保留所选原字节、越界与 NULL。MAKE_SET 使用同一个掩码和拼接内核，原生入口只验证掩码选中的字符串，并保留原 1105 文本。TiKV PB 保留原始字节行为。当前 MAKE_SET 接纳最多 64 个类型化字符串参数。

实际 SQL 核对了未选中的非法字节、掩码选中后诊断、负掩码、零掩码和 NULL。84 项共享表达式、71 项执行器集成、独立 SDK 的 448 项表达式、122 项执行器和 3 项 Endpoint 测试通过。限定 Clippy 和根 lint 通过。性能未测。
