# SHA、SHA1 和固定长度的 SHA2

task #74 固定为 TiDB `c29dccfd83213e42ef8d0f56f57ae9bbd5310753` 和 SDK `070c1b2cad01fe60ecc4fdb108fbd824bb7c4ca0`。

原生 SHA 和 SHA1 对类型已确定的字符串叶子调用 SDK 的 SHA1。SHA2 的长度为有符号整数字面量 0、224、256、384、512 时使用 SDK 的 SHA2。长度 0 与 256 都使用 SHA-256。动态或无效长度保留原生行为。实测无效长度在原生 SQL 返回 NULL 且无告警，在 SDK PB 返回 NULL 并给出 1583 告警。

实际 SQL 投影计数从 (0,0) 变为 (1,1)。核对二进制非 UTF-8 字节、多字节文本、空值、摘要宽度和字段声明。78 项共享表达式、24 项 SQL、限定 Clippy、格式及根 lint 通过。未测性能。
