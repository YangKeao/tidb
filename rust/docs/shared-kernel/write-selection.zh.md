# UPDATE 和 DELETE 的本地 BIGINT 筛选

TiDB 源码固定在 `f58ced4dd3d1d66fddf87d3fd3d140274b53a21c`，SDK 固定在 `2e123f71eb9b20e6e46b32110d60f895f7d8830b`。

开启共享筛选实验后，UPDATE 和 DELETE 的本地 Selection 可以把有符号 BIGINT 的七种比较交给共享表达式程序。每个比较的两个操作数须为直接列或字面量。混合筛选继续走原路径。执行器的扫描融合现在读取语句实际使用的 TiKV 下推黑名单，使明确保留在本地的谓词进入本地 Selection。

实际 SQL 用黑名单将 `<=>` 和 `<>` 留在本地。UPDATE 选中相等及两侧均为 NULL 的行；DELETE 跳过 NULL 比较，并在降序 LIMIT 下删除预期行。两条语句均核对共享批次、告警及最终表数据。只撤回扫描融合修正会使同一黑名单用例记录零个共享程序。

81 项共享表达式测试、58 项执行器集成测试通过。DELETE 回归筛选通过 4 项、忽略 1 项，下推筛选通过 1 项。功能关闭构建、限定 Clippy 和根 lint 通过。性能未测。
