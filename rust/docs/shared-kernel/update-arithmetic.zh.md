# UPDATE 的类型化 BIGINT 赋值

TiDB 固定在 5e90dde68ceba368ab6f467e6f80cc019274950b，SDK 固定在 2e123f71eb9b20e6e46b32110d60f895f7d8830b。

显式开启共享投影实验时，两叶有符号 BIGINT 加、减、乘赋值在准备时编译一次，通过共享 RPN 值接口读取原来的物理行或旧行块。实际 UPDATE 确认三份程序跨两行执行六次，两个相关赋值都读取写入前的值。提交、声明转换和回滚由原有 UPDATE 流程执行。后行的 1690 算术溢出及 TINYINT 赋值 1264 与原执行一致，两项都保留表的原状态。

81 项共享表达式、56 项执行器集成测试、功能关闭构建、限定 Clippy 和根 lint 通过。聚合测试目标的 update_ 筛选为 20 项通过、8 项忽略、1 项 DEFAULT 表达式解析失败。父版本用同一入口复现同一失败，保留了错误目标名的首次命令记录。使用现有一行值接口，性能未测。
