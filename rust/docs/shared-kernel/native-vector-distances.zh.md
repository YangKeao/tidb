# 原生向量距离

TiDB 固定在 e1bc3db29b2c4d33cffdc4f0b60baa16b530c6a6，SDK 固定在 1e3cea745b4a173b8ef7116e822078e7032f964b。

原生向量列调用 SDK 的 L1、L2、负内积和余弦距离。SQL 对照覆盖了 DOUBLE 字段、输入 NULL、零向量的 NaN→NULL 和不同维度的 1105。原生维度诊断保留消息和求值来源，省去 SDK 编解码异常附带的 Rust 源码位置；原有 PB 入口继续使用自身诊断。

81 项共享表达式、38 项 SQL 和 569 项独立 SDK 检查通过，关闭共享功能的表达式库编译也通过。共享读取仍复制向量数据，未测性能。
