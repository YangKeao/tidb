# BIN 和 OCT 的 BIGINT 格式化

task #81 固定为 TiDB `b467d4a4999e5fbcf0842557e7beef98a5927202` 和 SDK `6f3dd83a0357a7ea7cdbd77bdaa057c9f854ee03`。

原生 BIN 和 OCT 对已定型的有符号或无符号 BIGINT 使用 SDK 原有函数，保留完整的 64 位位模式。其他参数类型或转换沿用原入口，其中字符串 BIN 的截断告警已对照验证。
