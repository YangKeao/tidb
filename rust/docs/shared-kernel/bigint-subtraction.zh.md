# 有符号 BIGINT 减法

task #63 的产品和测试提交为 `819a840727da1a766f7dae466561a7a21e29cc19`，SDK 仍为 `1290817a57f7c8e88d52f64a1754b0e67712cec1`。

本地有符号 BIGINT 减法沿用 TiKV 原有 IntIntMinus 和共享整数调用。左值为 NULL 时跳过右侧，溢出时沿用原生诊断的表达式文本。无符号减法、PB 路径和默认选路沿用原有接纳范围。

实际 SQL 投影计数由 (0,0) 变为 (1,1)。边界值与 NULL 的结果、字段和告警均一致，原生和共享各消耗六次 RAND。另两条 SQL 分别验证低于最小值和超过最大值时都返回原 1690／22003 错误，消息逐字一致。无符号 SQL 计数为 (0,0)。

固定版通过 70 项共享表达式、16 项 SQL、限定 Clippy、根 lint 及格式验证。本批未测性能。验证目录 `evidence/bigint-subtraction/` 可重建 7 对跟踪源码树，其中 5 对固定到产品提交。清单包含 35 条记录，`SHA256SUMS` 的 SHA-256 为 `d2b1eb4202ed1a04b14334805e9036de1763aadb783540a5ca15f44d2ee81f42`。
