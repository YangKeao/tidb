# 窗口查询的共享计算键

TiDB 验证固定在 `5b7010678f98842453be6a89b5ae6bd764021a7a`，SDK 固定在 `2e123f71eb9b20e6e46b32110d60f895f7d8830b`。

真实 SELECT 在窗口输入的投影中计算 `g+1` 分区键和 `v-1` 排序键。物理计划与批次计数同时核对该投影。普通和流水线窗口各自覆盖直接输入和 Shuffle 输入，四种配置都运行一个共享程序，并保留 NULL 分区、NULL 排序和并列名次的原结果与告警。

用例通过有限子查询将投影估算控制在一个执行器批次以下，使投影使用已有的串行共享路径。初始开放范围查询选择了原生并行投影，记录零个共享程序。此次只增加验证。

60 项执行器集成、14 项窗口筛选、限定 Clippy 和根 lint 通过。性能未测。
