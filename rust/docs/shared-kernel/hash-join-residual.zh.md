# Hash Join V2 的本地 BIGINT 剩余条件

TiDB 固定源码为 `4b9b3c71ddbbf726c2c5b8a9ea7edf5e180b3612`，SDK 固定在 `2e123f71eb9b20e6e46b32110d60f895f7d8830b`。

开启共享筛选后，向量化的内连接和左右外连接可将两个直接有符号 BIGINT 操作数的比较交给共享表达式程序。每个探测工作线程准备一次，后续候选批次复用。既有连接继续生成候选和重建行；半连接与反连接仍读取原生三值筛选结果。编译会核对两侧拼接后的字段声明。

真实 SQL 在两个输入都含 NULL 的表上验证内连接、左右外连接及 NOT EXISTS，比较结果字段、行及告警，同时以旧版 Hash Join 作内外连接对照。仅撤回构建器选路，同一用例记录零个共享程序。用例比较无 ORDER BY 的结果集合，避免把不同连接实现的出行顺序纳入合同。

81 项共享表达式、59 项执行器集成、功能关闭构建、限定 Clippy 和根 lint 通过。宽泛 JOIN 筛选有 5 项通过、1 项在固定父提交同样失败（缓存索引连接参数重绑）；执行器库测试在两版都因 7 处测试未初始化 `clause_message` 无法编译。性能未测。
