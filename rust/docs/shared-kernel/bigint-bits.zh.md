# BIGINT 位运算与无符号输出

task #70 产品和测试固定为 TiDB `f55ebdec6b4965660aef1092e4ead137521a296c`。SDK 仍为 `47c439a980528603ef437ec8a682b67d5b5bfba3`。

BIGINT 的与、或、异或、取反、左移、右移及 BIT_COUNT 复用原 TiKV 位核。位运算保留无符号输出与完整 64 位，BIT_COUNT 保留有符号输出。两类 BIGINT 输入都读取原始位模式，负移位和达到 64 的移位量均为零。左操作数为 NULL 时仍按原生合同访问右操作数。

类型化对照覆盖四种符号组合、最高位、NULL 和重复物理行。实际 SQL 投影共享计数从 (0,0) 变为 (1,1)，字段、结果和告警一致。NULL 左值仍使四行各消耗一次 RAND。固定 245 族清单新增 7 个限定接纳映射，累计 39 个，另有 201 个尚无已核对映射和 5 个历史例外。

74 项共享表达式、20 项 SQL 和独立 SDK 444 项通过。限定 Clippy、根 lint 和格式通过。本批未测性能。验证目录 `evidence/bigint-bits/` 保存 12 对跟踪源码树，其中 6 对固定到产品版本，含原版本的接纳失败和早期编译失败。清单包含 57 条记录，`SHA256SUMS` 的 SHA-256 为 `45dc7247d9dcb4e6390d7fa160b90ed1751a758b165e41ef7c8885f182480de4`。
